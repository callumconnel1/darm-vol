# Software licence decision required before publication

The author has not yet selected a software licence. No licence grant is
implied. Do **not** publish or redistribute the package publicly on PyPI
until Callum Connell has approved the licence and provided its full text in
a `LICENSE` file.

The most common permissive options are MIT, BSD-3-Clause and Apache-2.0,
but no option has been selected automatically. Confirm rights in any
incorporated third-party materials before choosing.

The release workflow intentionally fails while `LICENSE` is absent.
